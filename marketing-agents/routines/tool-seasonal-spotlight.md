# Routine: Tool or Seasonal Spotlight

Schedule: monthly, 1st at 09:00 ET

Run the Clearing playbook "Tool or seasonal spotlight".

1. Pick this month's focus: an owned tool (the bookkeeping-hours calculator or the
   trust-accounting readiness quiz) or a seasonal moment (month-end close, tax season,
   year-end owner statements).
2. Draft outcome-first, calm and benefit-led, pointing to the tool or the timely action.
3. Confirm any product or pricing detail against clearing-context.md; do not state
   unconfirmed pricing or integrations.
4. Include the banking disclosure if funds, deposits, or insurance are mentioned.
5. Run the core QA gate, then the Clearing Pre-Flight.
6. Write review/tool-seasonal-spotlight-<date>.md (and .html if a card), Status NEEDS
   REVIEW. Log the run.

Do not publish.

---

## Clearing Pre-Flight checklist

Run after the core QA gate. All items must pass before writing to review/.

- [ ] No em dashes anywhere in the draft.
- [ ] Every statistic has a named source recorded in the header or body.
- [ ] Tool URL verified against clearing-context.md or flagged as unconfirmed.
- [ ] No pricing stated that is not confirmed in clearing-context.md.
- [ ] Banking disclosure present if funds, deposits, balances, or insurance are mentioned.
- [ ] Clearing is not called a bank or a property management software.
- [ ] No legal or compliance outcome promised.
- [ ] Brand kit flag present if any visual card is referenced (kit is not locked).
- [ ] Seasonal timing is appropriate for the current month.
