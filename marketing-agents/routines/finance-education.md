# Routine: STR Finance Education Post

Schedule: weekly, Monday 09:00 ET

Run the Clearing playbook "STR finance education post".

1. Pick this week's pain point or teaching angle (for example reconciling across Stripe and
   Airbnb, closing the books faster, clean owner statements). Check memory/memory.md for
   recent topics and avoid repeats.
2. Draft: name the chore and the hours it eats, teach one useful thing, show the automated
   way, close with a calm, benefit-led CTA. Relief, not hype. Any figure traces to the
   source library and is current.
3. If banking, deposits, or insurance comes up, include the required disclosure.
4. Run the core QA gate, then the Clearing Pre-Flight.
5. Write review/finance-education-<date>.md (contract header + post), Status NEEDS REVIEW.
   Log the run.

Do not publish.

---

## Clearing Pre-Flight checklist

Run after the core QA gate. All items must pass before writing to review/.

- [ ] No em dashes anywhere in the draft.
- [ ] Every statistic has a named source recorded in the header or body.
- [ ] Banking disclosure present if funds, deposits, balances, or insurance are mentioned.
- [ ] Clearing is not called a bank or a property management software.
- [ ] No legal or compliance outcome promised.
- [ ] No pricing or integration stated that is not confirmed in clearing-context.md.
- [ ] Brand kit flag present if any visual card is referenced (kit is not locked).
- [ ] Topic not repeated from the last four finance-education runs (check run-log.md).
