# FundMore Brand Skill

FundMore is Canada's AI-powered mortgage and lending infrastructure company. It builds
decisioning and automation tools for lenders -- banks, credit unions, and mortgage companies.
Everything here reflects the current brand canon.

## How to use this skill

1. For copy tasks, read `references/copy-bank.md` for the full, voice-tested snippet library
   by persona and channel.
2. For product accuracy, terminology, personas, and regulatory context, read
   `references/fundmore-context.md`.
3. For the full visual identity, voice rules, competitive positioning, and scaffolding,
   read `skills/fundmore-brand.md`.
4. Always end by running the **Pre-Flight Checklist** (in skills/fundmore-brand.md) before
   you deliver anything.
