# BrokerBot Canadian Context, Product, and Glossary

Use this file when you need to describe the product accurately, define a term, reference a
named tool, or write copy that depends on Canadian financial/regulatory context. Getting these
right is what separates BrokerBot from "a US product with a maple leaf sticker."

---

## Product and Features (canonical list)

Describe the product using these features. Keep names consistent across all content.

| Feature | What it does |
|---|---|
| Monthly home value updates | Automated, white-labeled property value reports sent to a professional's past clients each month, branded with the professional's name, logo, and face. |
| Equity insights / alerts | Surfaces changes in a homeowner's equity position to trigger refi, HELOC, and coverage conversations. |
| Renewal tracking | Tells the professional exactly when each client is approaching their renewal date (built for Canada's 5-year cycle). |
| Referral tools / engine | Helps grow a professional's network and generate referrals between verticals (brokers invite agents, agents invite appraisers, etc.). |
| AI lead pre-qualification | Built-in qualification of leads so professionals focus on the highest-intent prospects. |
| White-label experiences | The entire client-facing experience carries the professional's brand, not BrokerBot's. This is a core differentiator, not a feature toggle. |
| OPTA/FCT data foundation | Proprietary access to 18M+ Canadian residential property records (plus 7M commercial), the data moat behind every feature. |
| Bilingual delivery | English and French client-facing content. |

**Product positioning rule:** The customer's brand always comes first. BrokerBot is the engine; the professional is the face. Never let BrokerBot's brand sit ahead of the customer's in any white-label context.

## Canadian Financial and Regulatory Glossary

Use these terms naturally and correctly. They signal practitioner-level credibility.

| Term | Meaning | Copy guidance |
|---|---|---|
| PIPEDA | Personal Information Protection and Electronic Documents Act, Canada's federal private-sector privacy law. | Cite as proof of data handling compliance. "PIPEDA-compliant." |
| CASL | Canada's Anti-Spam Legislation, governs commercial electronic messages and consent. | Relevant to email/automation claims. "CASL-ready." |
| B-20 | OSFI's residential mortgage underwriting guideline (includes the stress test). | Reference when discussing the lending environment, qualification, and broker pressures. |
| OSFI | Office of the Superintendent of Financial Institutions, the federal banking/insurance regulator. | Use when citing the regulatory backdrop for lenders. |
| Filogix | A widely used Canadian mortgage origination/deal-submission platform. | Reference as a tool brokers "actually use" to signal ecosystem fluency. |
| OPTA / FCT | The data partners behind BrokerBot's 18M+ residential and 7M commercial property records. | Always the named source of the data moat. Never claim the records without crediting the source. |
| 5-year term / renewal cycle | The dominant Canadian mortgage term structure (vs. the US 30-year model). | The structural reason US platforms fail in Canada. Central to differentiation. |
| Refi | Refinance, replacing an existing mortgage with new terms. | Equity-alert trigger language. |
| HELOC | Home Equity Line of Credit. | Equity-alert trigger language. |
| Monoline lender | A lender that funds mortgages exclusively through the broker channel (no retail branches). | Use in lender-vertical copy. |
| AMC | Appraisal Management Company, an intermediary that assigns appraisal work. | Use in appraiser-vertical copy; AMCs are the "commodity" competition appraisers want to escape. |
| Book of business | A professional's full base of past and active clients. | Core practitioner term; the asset BrokerBot protects. |
| Possession day | The day a real estate buyer takes ownership. | Agent-vertical timing reference ("stay their agent long after possession day"). |

## Bilingual (English / French) Guidance

BrokerBot is a bilingual Canadian brand. When producing French content:

- The brand name stays **BrokerBot** (do not translate it) and the tagline treatment follows the same lowercase logic.
- French copy must be **written or reviewed by a fluent speaker**, not machine-translated. Quebec French marketing conventions differ from European French.
- The voice rules still apply: punchy, stat-led, loss-aversion, no anglicism-heavy buzzwords. The em-dash ban applies in French too.
- Quebec has additional language and consumer-protection requirements (e.g., French-first obligations). Flag any France-vs-Quebec or compliance questions for human confirmation rather than guessing.
- Stats and product names stay identical across languages; only the surrounding copy is localized.

When asked for French copy, produce a best-effort draft and explicitly note that it needs native-speaker review before publishing.
