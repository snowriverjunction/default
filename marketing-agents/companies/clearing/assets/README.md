# Clearing Brand Assets

Add the following master files to this folder, exported from the brand kit:

| File | Description |
|------|-------------|
| clearing-icon-light-bg.png | Icon mark only, teal/blue/violet segments on white background |
| clearing-icon-dark-bg.png | Icon mark only, on navy gradient circle background |
| clearing-logo-light.png | Full lockup (icon + wordmark), for light backgrounds, navy text |
| clearing-logo-dark.png | Full lockup (icon + wordmark), for dark backgrounds, white text |
| clearing-icon-light-bg.svg | SVG version of icon on light background |
| clearing-icon-dark-bg.svg | SVG version of icon on dark background |
| clearing-logo-light.svg | SVG full lockup for light backgrounds |
| clearing-logo-dark.svg | SVG full lockup for dark backgrounds |

Usage rules are documented in brand.md. Never recreate or redraw the icon -- always use
these master files.
