## Segmentation Notes

Adjust messaging for these key segments:

| Segment | Key modification |
|---|---|
| **Small operators (< 25 doors)** | Emphasize ease of use and time savings over scale. Adjust case study to a smaller operator. Reduce emphasis on team/headcount metrics. |
| **Mid-market (25–200 doors)** | This sequence is optimized for this segment. Use as-is. |
| **Enterprise (200+ doors)** | Swap in enterprise case studies. Add references to API access, custom integrations, and dedicated account management. Extend sales cycle expectations. |
| **Operators currently on a competitor** | Increase emphasis on migration safety (Email 5). Add a comparison-specific email between Emails 3 and 4. |
| **New to professional management** | Reduce jargon. Add more educational content in Emails 1–3. Reframe from "switching" to "starting right." |
